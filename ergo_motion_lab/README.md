# ErgoMotion Lab

Real-time ergonomics and time-motion study toolkit built with Flet and Flutter.

## Quick Start

1. **Clone** in GitHub Codespaces.
2. Install dependencies (Python 3.10 recommended):
   ```bash
   pip install -r requirements.txt
   ```
   *Note:* `tflite-runtime` wheels are not available for Python 3.11+.
   Use Python 3.10 or install a compatible wheel manually.
3. Run in the browser:
   ```bash
   flet run app/main.py --web
   ```
4. Android APK is built automatically by GitHub Actions.
